# 系数查表节点 `GetSDr` / `GetSMr`：语义与全部轴表（2026-10-20）

对象：`FUN_1802a0fa0`（注册名 `GetSDr`）与 `FUN_1802a2940`（注册名 `GetSMr`），
它们分别是玻璃"挠度系数 μ"与"板面跨中弯矩系数 m"的取数节点，也是上一轮 `VERIFICATION.md` B10 的缺口。

**结论先说**：两个节点是同一个模板的两份拷贝——读 `$0..$3` → 归一化成边长比 → 按 `$2`
（材料/构件代码）与 `$3`（支承/边数代码）选一对内嵌轴表 → 交共享插值器 `FUN_180299d50`；
少数分支直接返回常数。**被引用的 38 个轴表全部解出自描述布局**，4 个锚点全部命中原版打印值，
外片应力 `6.726054` 随之按"表→θ→η→σ"整链复现（见 `modules/glass-stress-transparency.md` §5）。

| --- | --- | --- | --- |
| ① | 分支 → 轴表映射 | **闭合** | 23 条分支逐条转录，脚本可重跑（§3） |

| ④ | 代码（`$2/$3`）语义 | **部分** | 11/0/1/2/3、4/6 有调用面证据；`GetSMr` 的 20/25/30 细分未定（§6） |

## 2. 节点流程（逐句对得上伪代码）

```text
this  = CXMap::evalParams(param_1, param_2)          // 求值形参表
$0..$3 = CXDict::look_string(this, "$0".."$3")       // 缺省时指针为空
if (argc < 2)        → 退化分支：FUN_1802986b0(0x7fffff 哑常数)  // 不是查表
elif (argc == 2 或 命中 "$2∈{0,9,20,[30,40),42}") → 直接查 m/μ 主表
else                 → 按 $2（必要时再按 $3）选表；未命中 → 常数 0.0
ratio = min($0,$1)/max($0,$1)                        // 两个特例见 §3 注
value = FUN_180299d50(ratio, xAxis, yAxis)           // 线性插值 + 两端钳制
result = CXConstant(value)                           // 值在对象 +0x8，与其它节点一致
```

`FUN_180299d50(x, xAxis, yAxis)` 的读法（已反向确认，两个轴**都**带计数头）：

```text
count = (int)xAxis[0]                 // 计数存成 double
if (x <= xAxis[1])        return yAxis[1]        // 下端钳制
if (x >  xAxis[count])    return yAxis[count]    // 上端钳制
i = 首个满足 x <= xAxis[i] 的下标
return yAxis[i-1] + (yAxis[i]-yAxis[i-1]) * (x-xAxis[i-1])/(xAxis[i]-xAxis[i-1])
```

## 5. 锚点：与原版自印值对照

原版对冻结样例打印的系数（`frozen-report-head.txt`）：

```text
μ: 挠度系数,按边长比a/b查 表6.1.3得: 0.00406
m: 玻璃板面跨中弯曲系数,按边长比a/b查表 6.1.2-1得: 0.0442
```

| 锚点 | 节点/分支 | ratio | 表值 | 原版打印 | 差 |
| --- | --- | --- | --- | --- | --- |
| μ 玻璃 2 参 | `GetSDr` argc==2 | 1.0 | 0.00406（clamp-high） | 0.00406 | 0 |
| μ 玻璃 `$2=11` | `GetSDr` `$2=11` | 1.0 | 0.00406（clamp-high） | 0.00406 | 0 |
| m 玻璃 2 参 | `GetSMr` argc==2 | 1.0 | 0.0442（clamp-high） | 0.0442 | 0 |
| m 玻璃 `$2=0` | `GetSMr` `$2∈{0,…}` | 1.0 | 0.0442（clamp-high） | 0.0442 | 0 |

两条独立路径（2 参 / 代码分支）在同一 ratio 上给出同一个值，说明"缺 `$2` 时默认走主表"不是猜测。
后续链路（θ→η→σ）见 `modules/glass-stress-transparency.md` §5：σ 外片 `6.726054` 由
`6×0.0442×0.919618×1000/36×η1` 复现到 9.8e-8。

## 6. 观察、更正与未定

1. **更正**：B10 曾记录"`GetSDr` 19 个 / `GetSMr` 22 个 `DAT_` 地址按该布局解析全部失败"。本轮用**同一 PE**
   把两个节点的全部引用地址（38 个去重后）逐个解析，**全部成功**，count 均为 11/13/15/16 的整数 double。
   该负面结论未能复现，作废；以可重跑脚本为准。
2. **`$2 = 22` 的 tie-break 是空转**：`0x180544180` 与 `0x180544240` 字节完全相同（sha256 相同），
   分支存在但结果不变。脚本把这条作为观察项断言。
3. **两个节点的 ratio 特例写法不同**：`GetSDr` 的 `$2=2` 非四边分支是 `($1/$0)×0.5`，
   `GetSMr` 的 `$2=2` 非六点分支是 `$0/($1×0.5)`，不可互换（后者对调两个边长会改变结果）。
4. **原版标签对调**：计算书里 μ 标"表6.1.3"、η 标"表6.1.2-2"；JGJ102-2003 的实际编号是
   μ 为表 6.1.2-2、η 为表 6.1.3。这是**原版文案缺陷**，复刻时必须照抄同样的文字，不能"改正"。
5. **代码语义只证到这一步**：`$2` 是材料/构件代码，`11` 由 `ALUS_/ALUC_/ALHCP_` 模板传字面量（铝板族）；
   `0/1/2` 来自 `PRJGLASS`；`3` 与石材的 3 参调用**未对上**（`STONECAL` 取值未取证，只有它是 3 时才落
   `$2=3` 分支）；`GetSMr` 的 `$3 ∈ {20,25,30}` 细分表语义未知（`LINKNUM` 只解释 `4`/`6`）。
6. `GetSDr` 的 `$2=1` 常数 `0.013` 与 `mu.glass.2arg` 在 ratio=0 处的 `0.01302` 不等，取哪个由代码路径决定，
   不要当成同一常量。

## 7. 仍未覆盖

- `GetSMr` 的 `$3 ∈ {20,25,30}` 三个石材/铝板细分表**没有原版打印锚点**（样例里没有该分支），只有字节层证据。
- 同类查表节点 `GetNg`（η，表在 `lookup-tables.md`）、`GetMetalNg`、`GetLambda` 未按本口径逐个复核。
- 这些系数最终怎样落进 `.cwx` 的 `HWKCalc_*` 记录仍未解（B6/B11）。
