# 数据层（L7）可读性验证：SQL 库直接可查（2026-10-19）

结论：**L7 不再是黑箱**。数据不在加密的 `xdf` 里独占——主要业务数据在 SQL Server / LocalDB 的
`XWall.mdf`（主库）、`XWallTem.mdf`（规范/热工库）、`UserGlazing.mdf`（用户玻璃库）里，且**已存在只读副本库**
`HWKCOPY_XWall` / `HWKCOPY_XWallTem` / `HWKCOPY_UserGlazing`。

## 1. 怎么读到的（可复现）

1. 把 `XWallTem.mdf` **连同 `XWallTem_log.ldf` 一起**复制到本轮目录（只复制，不动原件）；
1. 用 `System.Data.SqlClient` attach 到 `(localdb)\v11.0`：

```powershell
$cn.ConnectionString = "Data Source=(localdb)\v11.0;Integrated Security=True;AttachDbFilename=$mdf;Connect Timeout=60"
```

1. 查 `sys.tables` / `sys.partitions` / `INFORMATION_SCHEMA.COLUMNS`，完成后 `sp_detach_db` 卸载。

> 关键坑：**只复制 mdf 不复制 ldf 会 attach 失败**（"The log cannot be rebuilt when the primary file is read-only"）。
> 两个文件都要复制，且保持原文件名。

## 3. 为什么这改变优先级

| 资产 | 现状 | 可替代性 |
| --- | --- | --- |
| 计算机制（注册/求值/符号模式） | L4 已闭合 | 可从代码反推 |
| 公式文本 | 2082 条明文（`计算模板`） | 可从代码反推（已有 `formulas.md`） |
| **规范数值/材料/型材/风压数据** | **本文件证明可查** | **无替代来源**，只能取 |
| 计算书/绘图/UI | 未取证 | 只能实机观察 |

→ 因此"继续抠 379 个节点里剩下的 30 条算式"的边际收益低于"把 2082 条公式 + 85 张表的数值绑定起来"。

## 4. 下一步（按 ROI 排序）

1. **导出全部 schema + 样本**：`XWall`(8) + `XWallTem`(56) + `UserGlazing`(21) = 85 张表的
   列名/类型/主键/前 N 行 → 建 `migration_workspace/db-dump.md` + `raw/db/*.json`；
1. **公式↔参数↔数据列绑定**：把 `计算模板` 的 2082 条公式里的符号，对上 `cxmap-entries` 的 379 参名表，
   再对上数据表列（例如风压/强度/密度）→ 产出"可执行公式"清单；
1. **一条业务链端到端对照（L8 最小切片）**：如玻璃 U 值或幕墙风荷载，原版界面取值 vs 用上表数据+公式复算。
