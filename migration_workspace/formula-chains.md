# 公式链起步：风荷载（WLS → WLD）逐字转录（2026-10-19）

来源：`HWKCOPY_XWallTem.计算模板`，`CONTEXT` 为 GBK `varbinary`，本文档是**原文转录**（非释义）。
选这条链的理由：它是所有幕墙/门窗体系的起点，且只有两层（标准值 → 设计值），最容易验证。

## 1. `WLS` 风荷载标准值（IID=1）

```text
   Wk: 作用在${GetBoardType(PRJGLASS)}上的风荷载标准值(kN/m^2)
   μz: ${z}m高处风压高度变化系数(按${REGION}类区计算): (GB50009-2001  7.2.1)
         μz=${μh}×(z/10)^${α2}=${μzcal} ${IsLess(μzcal,μz):+由于${μzcal}<${μz},取μz=${μz}}
   μf: 脉动系数  :                  (GB50009-2001  7.4.2-8)
        μf=0.5×35^(1.8×(${α}-0.16))×(z/10)^-${α}=${μf}
   βgz: 阵风系数  :                 (GB50009-2001  7.5.1-1)
        βgz=${GetKk(REGION)}×(1+2×μf) = ${βgz}
   Wk=${IsNEqual(γ0,1):+γ0×}βgz×μz×μsl×W0             (JGJ102-2003  5.3.2)
     =${IsNEqual(γ0,1):+${γ0}×}${βgz}×${μz}×${μs}×${ω0}
     =${ωk} kN/m^2  ${WkLESS1:+\r\n   Wk<${ωklim}kN/m^2,取Wk=${ωklim}kN/m^2}
```

要点（**来自原文，不是推断**）：

- `μz` 按高度 `z` 与地区类别 `REGION` 计算，带"取小值"分支 `${IsLess(μzcal,μz):…}`；
- `μf = 0.5 × 35^(1.8×(α-0.16)) × (z/10)^(-α)`，`βgz = GetKk(REGION) × (1+2μf)`；
- `Wk = [γ0×] βgz × μz × μsl × W0`，另有下限钳制 `Wk < ωklim` 时取 `ωklim`；
- 规范出处原文保留了四处：GB50009-2001 7.2.1 / 7.4.2-8 / 7.5.1-1、JGJ102-2003 5.3.2。

## 2. `WLD` 风荷载设计值（IID=2）

```text
   W: 风荷载设计值: kN/m^2
   γw : 风荷载作用效应的分项系数：${γwf}
       按《玻璃幕墙工程技术规范》JGJ 102-2003  5.1.6条规定采用
   W=γw×Wk=${γwf}×${ωkt}=${ω}kN/m^2  ${IsEqual(PRJGLASS,42):+
   Wf\:负风压作用下风荷载设计值\: kN/m^2
   Wf=γw×Wkf=${γwf}×(${ωktx})=${ωx}kN/m^2 }
```

- 正压：`W = γwf × Wk`；负压：`Wf = γwf × Wkf`；
- 负压段落被 `${IsEqual(PRJGLASS,42): … }` 条件包裹（是否显示取决于玻璃类型）。

## 3. 这条链需要的输入（按原文符号列出）

| 符号 | 作用 | 候选来源 |
| --- | --- | --- |
| `z` | 计算高度 | 用户输入（工程信息/标高） |
| `REGION` | 地区类别（A/B/C/D） | 工程信息 + `省表`/`风压数据` |
| `ω0` / `μsl` | 基本风压 / 局部体型系数 | `风压数据` 表 + 体型系数输入 |
| `μh`、`α2`、`α` | 高度系数基准/指数 | 规范表（`规范表`/`标准规范表`）或节点 `GetKz`/`GetKk` |
| `γwf` | 风荷载分项系数 | 用户/规范默认值（1.4 等） |
| `γ0` | 结构重要性系数 | 用户输入 |
| `PRJGLASS` | 玻璃类型码 | 工程/构件属性 |
| `ωklim` | 最小风压限值 | 规范表 |

## 9. `param_4` 分叉已解（2026-10-19，第 1 项完成）

`fun_180255170` 的尾部（第 146–162 行）说明白了结构：

```c
dVar4 = pow(param_2 / 10.0, -(double)CONCAT44(uVar7,uVar6));        // (z/10)^(-α)
dVar5 = dVar4 * (param_3 + param_3) * CONCAT44(uVar13,uVar12) + 1.0; // 1 + 2·param_3·C·(z/10)^(-α)
dVar4 = dVar5;
if (param_4 != '\0') {
  if ((!bVar1) || (dVar5 < CONCAT44(uVar11,uVar10))) {
    if (bVar2 && CONCAT44(uVar9,uVar8) <= dVar5) dVar4 = dVar5; else dVar4 = CONCAT44(uVar9,uVar8);
  } else dVar4 = CONCAT44(uVar11,uVar10);
}
return dVar4;
```

结论（实测，非推断）：

1. **`param_4` 是"是否施加钳制"的开关**，不是选参数分支；
2. 之前被我当作"μh 候选"的两组值——`1.65/1.78` 与 `1.40/1.48`——其实是**上界与下界**（`uVar10/11` = 上界，`uVar8/9` = 下界）；
3. 真正的算式是 `1 + 2·param_3·C1213·(z/10)^(-α)`，其中 `α`（`uVar6/7`）在 A/B/C/D 下为 `0.12/0.15/0.22/0.30`，与 GB50009 地面粗糙度指数一致；
4. 因此 `μh/α2` **不是**这个函数的返回值——先前"三组候选"的假设作废，`calc-wind.py` 里那三行候选应改为"钳制区间"用途。

未定：`C1213`（0.12/0.14/0.23/0.39）在公式里的名字，以及 `bVar1`/`bVar2` 两个标志的判定条件。

## 10. 第 3 项：另一条短链预演 —— 玻璃板块自重 `WWEIGHT`（2026-10-19）

原文（`计算模板.WWEIGHT`，摘算式部分）：

试算（面积 1.5×1.5=2.25 m²，γGfm=1.2 为候选值）：

| GLS_STRUCT | 厚度 | GSAK (kN/m²) | G (kN) |
| --- | --- | --- | --- |
| 0（单片） | 6 mm | **0.1536** | 0.4147 |
| 2（两片） | 6+6 mm | **0.3072** | 0.8294 |
| 3（三片） | 6+6+6 mm | **0.4608** | 1.2442 |

**为什么这条适合做预演**：

1. 只依赖 1 个 DB 值（密度）+ 2 个构件输入（厚度、面积），链路最短；
2. `0.1536 kN/m²`（6 mm 玻璃）与工程常识一致，量级自检通过；
3. 分支结构（`GLS_STRUCT` 0–4）覆盖了"单片/中空/夹层/三片/四片"，能顺带验证分支覆盖写法。

## 11. α 与 Kk 双源印证；μz 形式为"推得"（2026-10-19）

| REGION | A | B | C | D（其它） |
| --- | --- | --- | --- | --- |
| `α`（`uVar15/16`） | 0.12 | 0.16 | 0.22 | 0.30 |
| `Kk`（`uVar17/18`） | 0.92 | 0.89 | 0.85 | 0.80 |

同函数里还有：

```c

dVar14 = pow(35.0, ((double)CONCAT44(uVar16,uVar15) - 0.16) * 1.8);              // 35^(1.8(α-0.16))
```

## 12. 关键突破：`I10` 定名 + 新规范 βgz 形式（2026-10-19）

`LOAD_WINDSTANDCALC`（6422 字符，风荷载标准值计算）原文直接给出了 2012 版形式：

```text
I10: 10米高名义湍流度，对应A、B、C、D类地面粗糙度，分别取 0.12、0.14、0.23、0.39
βgz = 1 + 2×g×I10×(z/10)^(-α)
     = 1 + 2×${GLOB_g}×${GetI10(REGION)}×(${LOAD_ELEVATION}/10)^(-${GetAlpha(REGION)})
     若 βgz > βgzc 则取 βgzc            （IsLarge 分支）
     并须满足《工程结构通用规范》下限：1 + 0.7/μz^0.5
μz ：查表（LOAD_NeedTruncHighKuz）或公式 μh×(z/10)^α2（LOAD_NeedCalcKuz）二选一
```

**两处独立印证**：

1. `I10 = 0.12/0.14/0.23/0.39`（原文）恰好等于我在 `fun_180255170` 里解码出的 `uVar12/13`
   → 之前那个"未命名的 C1213"就是 **I10**；
2. 该函数里的 `dVar5 = (z/10)^-α × 2g × I10 + 1` 与原文 `1+2g·I10·(z/10)^-α` **逐项对应**，
   所以 `fun_180255170` 就是 **βgz 计算函数**（不是 μz）。

`GetAlpha`/`GetI10` 两组常量也已由 `decode-node-constants.py` 独立导出（`GetAlpha` 见 `node-constants.md`）。

### 两种形式并存 —— 这解释了「钳制」与「param_4」

| 形式 | 表达式 | 出处 |
| --- | --- | --- |
| 旧（2001） | `βgz = Kk×(1+2μf)`，Kk=0.92/0.89/0.85/0.80 | `WLS` 原文 + `GetKk` |
| 新（2012） | `βgz = 1+2·g·I10·(z/10)^(-α)`，并有下限 `1+0.7/√μz` | `LOAD_WINDSTANDCALC` 原文 |

`fun_180255170` 的 `param_4` 钳制开关、`IsBgzTruncHigh` 节点的上下界（1.65/1.78 与 1.40/1.48），
都是这套"公式值 + 截断值 + 规范下限"的产物。
