# L8 实机验证清单（离线侧已备妥的部分）

用途：把"反编译可读"升级为"数值验证"。所有步骤都设计成**一次跑完、证据可回收**，
避免反复上机。离线侧已把需要对照的公式、参数顺序、样例文件、检查点全部固定下来。

---

## 0. 需要你提供的环境事实（只需一次）

| 项 | 为什么要 |
| --- | --- |
| Windows 版本 + 是否装有 SQL Server LocalDB `v13.0` | 数据库路径已确定为 `(localdb)\v13.0` + `Initial File Name=%s` |
| 安装目录（默认 `C:\Program Files\...\XWallClient`？） | 定位 `XWall.mdf` / `Support\` |
| 是否有加密狗 | `GetHMMxValue` 约 1/89 概率触发，影响观测但不影响数值 |
| 是否允许复制 `XWall.mdf` 与 `Support` 目录出来 | 离线做 schema 对照 |

## 1. 一次上机要跑的三条链

按"最小但覆盖三种形态"选样例（均在安装包 `XWallClient\示例\`）：

| # | 体系 | 样例文件 | 验证目的 |
| --- | --- | --- | --- |
| A | 栏杆（三维栏杆） | `各种栏杆样例.cwx`（6.9 MB） | 走 FE 求解 + 结果表 |
| B | 幕墙（明框/隐框） | 示例目录中任一 `.cwx` 幕墙工程 | 走玻璃节点族（含 `CalGlassDisp`） |
| C | 门窗（普通门窗） | 示例目录中任一门窗工程 | 走 `HWKCalc_*` 门窗族 |

## 2. 每一步要抓的东西（可复现的最小证据集）

对每条链，按顺序执行并记录：

1. **打开工程前**：截图 `工程信息` / `计算参数` 面板（要能读出输入数值）
2. **执行计算**：菜单里的"计算"入口，记录**开始/结束时间**（秒级即可）
3. **结果**：截图结果表格（内力/位移/应力数值，含单位）
4. **计算书**：导出/打印计算书（PDF 或 doc），保存原文件
5. **工程另存为**：`另存为` 副本，命名 `A-栏杆-复算.cwx`
6. **数据库快照**：关闭程序后复制 `LocalAppDataFolder\HWKSoft\XWall\XWall.mdf`（+`.ldf`）与
   `XWallTem.mdf`，命名 `A-XWall.mdf`
7. **日志**：`XWallClient` 目录下如有 `*.log` / `*.txt` 一并带走

> 关键：**同一工程连续算两次**，比较两次结果是否逐位一致 —— 这直接验证 §9.4
> "随机许可校验不影响数值"的结论是否成立。

## 3. 离线侧已固定的对照目标

### 3.1 玻璃位移节点（`CalGlassDisp`）

已实测公式（`calculation-core.md` §9.2）：

```text
结果 = ms × qwk × aw⁴ ÷ dw × theta × 1e9
```

参数顺序（构造函数与 eval 两处独立证据一致）：

| 索引 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 名字 | `ms` | `qwk` | `aw` | `dw` | `theta` | `prefix` | `def` |

验证方式：从链 B 的输入面板读出 `ms/qwk/aw/dw/theta`（若界面显示的是别名字段，
用数值反推匹配），代入上式，与结果表里的位移值比对。

- `aw` 用 `pow(aw, 4.0)`，不是 `aw*aw*aw*aw`——比对时注意浮点差异量级
- 常数 `1e9` 已确认硬编码，若量纲对不上，说明还有一层单位换算在节点外

### 3.2 节点族（批量已跑）

`migration_workspace/nodes-<族>.md` 会给出每个节点的参名表与赋值表达式原文，
链 A/B/C 任一结果都可以直接在这张表里找到对应算子做比对。

### 3.3 数据层

抓回的 `XWall.mdf` 可离线解析（`scripts/mdf-scan.py` 已能出页结构与键名），
用于验证 §8 的假设：**计算参数键存在库里，且与引擎属性键同构**。

## 4. 判定标准

| 等级 | 条件 |
| --- | --- |
| 数值一致 | 同输入下，上式复算与原版结果相对误差 ≤ 1e-9（同量级浮点运算） |
| 结构一致 | 参名表、分支条件、常数与原版结果表的字段一一对应 |
| **不一致** | 任一不符 → 不得判"理解正确"，必须回查是哪一层（单位/顺序/分支/舍入） |

## 5. 已知边界（不因实机验证而放宽）

- 加密狗存在与否不改变数值，但改变外部调用次数；报告里必须分开写。
- 两次计算若结果不同，首先怀疑随机许可校验路径，其次怀疑 FE 求解的迭代容差。
- 只验证被点名的那条链，不外推到其他 73 个体系。
- 截图与计算书是"用户可见结果"，不等于中间量；中间量若拿不到，明确写 `NOT_RUN`。
